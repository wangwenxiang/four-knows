同一个模型，只让外面的 harness 自我迭代几轮，就能超过更高推理档位，成本最高还少 60%。 Sakana AI 与 UC Berkeley 这篇论文提出 RHI，让 Agent 递归改进自己的运行方式。 这里的 harness，可以理解成包在模型外面的工作流：不同 Agent 分别负责什么、遵循什么指令、彼此传递哪些信息，以及任务如何继续推进。 RHI 把整套工作流写成可修改的 Prompt。每轮执行后，它会比较当前版本和上一版本的结果，再根据反馈生成下一版 harness。 整个过程保持模型权重不变，调整的是 Agent 的角色、沟通方式和工作节奏。 在量化金融、机器人和制药领域的 30 个机器学习研究任务中，经过少量迭代的 Agent 超过了更高推理档位，推理成本最高降低 60%。 更有意思的是，输出长度几乎没有增加。性能提升主要来自更好的上下文管理：每个 Agent 只接收真正需要的信息，减少重复读取和无效沟通。 这篇工作会给 Agent 工程一个很直接的启发： 模型能力固定以后，仍有很大一部分性能藏在 harness 里。 以后 Agent 的自我改进，可能会先从重新安排角色、信息流和工作流程开始。 📎 arxiv: https://t.co/Ud5Jmvxzfx

昨天大家都在讨论 Pacing the Frontier：上千名前沿 AI 公司员工呼吁建立协调机制，在必要时放慢 AI 研发速度。几乎同一时间，扎克伯格在《华尔街日报》发表文章，给出了另一套答案。 这篇文章也很值得一起看。 扎克伯格认为，未来几年人们可能获得超越人类能力的超级智能。真正决定未来走向的，是这种能力最终集中在少数公司和机构手里，还是成为每个人都能使用的工具。 他也直接反驳了「AI 必然让大多数人失去工作」的叙事。在他的设想里，超级智能最大的价值来自发明：帮助普通人创办公司、开发新产品、发现药物，做出过去只有大型机构才能完成的事情。只要能力被广泛分配，未来可能出现更多工作和更多创业者。 我觉得最有意思的，是这两份声明对「危险来自哪里」给出了不同判断。 联名信担心研发速度太快，社会和安全机制跟不上；扎克伯格更担心力量过度集中，最后由少数机构决定谁能使用 AI、能用它做什么。前者希望保留一起踩刹车的能力，后者希望把方向盘交给更多人。 当然，Meta 本身就是开放模型路线的重要受益者，这篇文章既是一套价值判断，也是一场很明确的行业竞争。但他的提醒依然值得认真对待：以安全为理由把最强智能锁在少数公司手里，本身也可能制造新的风险。 两边其实有一个共同前提：超级智能离我们可能没有想象中那么远。 接下来真正要讨论的，或许是我们究竟更害怕 AI 跑得太快，还是更害怕最终只有少数人握着它。 Link: https://t.co/d0dTSvv7Ei
