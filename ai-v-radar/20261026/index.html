Claude Opus 做科研时，会把一个几乎人人都在用的调参技巧，当成「创意突破」。 Anthropic 这篇新论文里讲的这个细节很能说明今天的 Research Agent，实验做得越来越好，但还分不清什么才算真正的新想法。 Agent4Sci 把 Claude Code、Codex、Gemini 放进 20 个真实 ML for Science benchmark，让它们直接读论文、改代码、跑实验，再尝试超过论文原本的最好结果。 结果前沿 Agent 在所有 benchmark 上都找到了提升，Claude Opus 平均相对提升 10.4%。 但作者把轨迹拆开后发现，大部分提升来自熟悉的 ML 工程技巧：调超参、换优化器、ensemble、反复局部搜索。 真正的科研判断还比较弱。 它们经常高估一个想法的新颖性，GPU 放着不用，或者很快找到一个有效方向后，就一直在附近刷参数。 作者后来只加了三个很轻量的 Skill：科研构思、实验管理和定时自检。 Claude Opus 的平均提升从 10.4% 涨到 20.1%，Codex 也从 4.4% 涨到 8.1%。 所以 Research Agent 现在的瓶颈不在执行，在判断。三个轻量 Skill 就让提升翻倍，说明比起给它更多算力，先给它科研习惯更划算。 对于经常用 Claude Code 或 Codex 跑实验的朋友非常推荐阅读。 📎 arxiv: https://t.co/QPyDM8zVqF

Anthropic 最近开始建议企业「少用点 Subagent」，甚至把一些专家 Agent 重新合并回主 Agent Loop。 他们在多个企业项目中发现，单 Agent + Skills 的效果经常比复杂的多 Agent 架构更好。有个客户改成单 Loop 后，运行速度甚至快了约 2 倍。 原因很容易理解。 多个 Agent 之间反复交接任务，每次都要传递和总结 Context，信息容易丢失，延迟和成本也跟着增加。 Anthropic 现在更推荐让一个主 Agent 负责规划和执行，需要时再动态加载 Skills 和 Tools，把业务流程和领域知识留在可复用的组件里。 不过文章里有个细节值得关注。 他们曾把客服系统里的 Subagent 合并，延迟确实降低了，却让一个原本能完成的任务失败了，因为主 Agent 漏掉了向物流专家确认送达时间这一步。 所以作者强调，每合并一个 Subagent，都要用端到端 Eval 验证，尤其要检查哪些原本通过的任务突然失败了。 当然，并行研究、独立验证、Context 隔离这些场景，Subagent 依然有价值。 这样看来以后设计 Multi-Agent，可能得先问问自己，每个 Subagent 真的需要独立的 Context 和执行循环吗？ Anthropic 还开源了一套迁移工具，可以帮你分析现有架构，逐步合并 Subagent，并比较改动前后的质量、成本和延迟。很推荐做 Agent 工程的朋友试试。 原文：https://t.co/0CPabUlmF7

Since I'm now blocked by bluey from replying to this thread, I answer here by quote tweet the openAI construction has more to do with convex integration than anything else. In convex integration, the oscillations are typically built by hand and the iteration procedure creates wild weak solutions. The non-uniqueness construction of Albritton–Brué–Colombo used an unstable vortex to split solutions apart. The Córdoba–Martínez-Zoroa singularities amplify vorticity across scales by strain. In the openAI paper, a fluid instability is clever made so that the flow itself generates the oscillations: they grow by drawing energy from the background shear. The Reynolds stress then becomes the force that creates the collapsing smooth vortex. Using a physical instability to create the stress in this way has no precedent, and it is what produces a smooth force rather than a merely rough one. Some on these ideas are in the literature (e.g. Leibovich-Stewartson 1983) but the way they are combined is definitely insane and definitely nowhere in the literature previously. I also don't know of anyone suggesting that convex integration would play a role in the creation of a blow-up solution like this. On a technical level, the paper is unbelievable, maybe beyond what a human could have come up with but not beyond human understanding: there are several different groups of pde experts working on understanding it who say that they more or less understand now. I expect digestions soon td;lr: anyone saying that this OAI result is unsurprising is bullshitting sorry!
