科研 Agent 会提 idea 已经不稀奇了，难的是知道哪条真的值得继续做。 这篇 DiscoveryRSI 想让 Agent 学会筛选和改进研究假设。 它会围绕一个假设不断生成、修改和组合方案，同时要求每个假设都有明确证据、实验设计、判断标准和替代解释。 更关键的是，研究过程会反过来训练下一轮 Agent。 好的假设会保留下来，失败轨迹则用来定位研究流程哪里出了问题，再继续更新模型和 Harness。 两轮自我改进后，假设质量从 4.86 提升到 5.39，提升主要来自「可证伪性」和「数据是否真的能回答问题」。 还有一个挺有意思的结果： DiscoveryRSI-27B 生成的假设中，有 6.3% 和模型知识截止后发表的研究方向相似；GPT-6 是 2.5%，Claude Opus 5 是 2.3%。 这个指标当然不能直接等同于真正发现，但方向很值得关注。 科研 Agent 的自进化，不该只学会写得更像论文。 它还要逐渐学会判断，哪些问题值得追，哪些证据真的够，以及下一轮研究该怎么做得更好。 📎 arxiv: https://t.co/9ZAKfnIurj

had a lot of fun talking with @HarryStebbings about all things ai one line of questioning we went done - vertical vs horizontal agents, and how to build them im bullish on vertical agents, and i think you can create differentiation (from horizontal agents) in three ways: 1/ context: prompts, skills, tools - all of this is specific to your domain, pretty easy to provide, and gives domain specific context to the agent 2/ harness: harder to tweak than context, but can alter fundemental behavior of the agent 3/ model: hardest to tweak of all, but obviously changes behavior greatly i think most agent engineers these days are still tweaking 1 and 2 (in that order) nb: regardless of what layer you tweak at, as the base models change you should revisit your context/harness/model every 3-6 months (and generally remove cruft that is no longer needed) https://t.co/gmA8oyfxiX

和 @HarryStebbings 畅聊 AI 的方方面面，非常开心。 我们探讨的一个话题是：垂直领域智能体与通用智能体，以及如何构建它们。 我看好垂直领域智能体，认为可以从三个方面打造相对于通用智能体的差异化： 1/ 上下文：提示词、技能、工具——这些都与你的领域相关，比较容易提供，能为智能体补充领域专属的上下文。 2/ 运行框架：比上下文更难调整，但能改变智能体的根本行为。 3/ 模型：最难调整，但显然也能显著改变行为。 我认为，如今大多数智能体工程师仍在调整第 1 和第 2 层，而且通常先调整第 1 层。 注意：无论调整哪一层，随着基础模型变化，都应该每隔 3–6 个月重新审视上下文、运行框架和模型，并清理不再需要的冗余内容。 https://t.co/gmA8oyfxiX
