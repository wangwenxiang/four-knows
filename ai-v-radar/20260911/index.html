如果每天真实发生的 Agent 调用，都能反过来告诉模型「下一轮该学什么」呢？ NeoHorse-1 尝试把这件事做成一个持续训练闭环。 系统里的 Routing Harness 会根据任务难度选择模型，同时记录执行轨迹、工具调用和结果。 这些真实交互会被整理成训练数据。系统先判断哪些轨迹有效、哪里失败，再把任务按能力需求组织成课程，用来更新模型。 训练后的模型重新回到 Harness 里跑新任务，继续暴露新的能力缺口。 于是形成了一条很自然的循环： 执行任务 → 找到短板 → 组织数据 → 更新模型 → 再回到真实任务。 实验覆盖 10 个 benchmark。4B 模型平均分从 58.94 提升到 64.87，9B 从 65.60 提升到 69.04。 更值得注意的是，同样训练配置下，Routing Harness 收集的真实交互轨迹，比公开合成 Agent 数据平均高 6.26 个百分点。 现在 Harness 可能会逐渐从执行层走进训练层。 Agent 每天怎么被使用、在哪里失败，本身就可能成为下一版模型最有价值的数据来源。 📎 arxiv: https://t.co/wbXB44b0Lb
