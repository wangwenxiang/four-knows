一个 9B 模型，只加一套会持续进化的 Skill，平均表现就超过了没有 Skill 的 27B 模型。 Google Research 这篇 WikiSkill，研究的是一个大家都一直关注的问题： Agent 每轮任务都在产生经验，但这些经验如果一直散落在执行轨迹里，下一轮其实很难真正复用。 WikiSkill 给 Agent 加了一层持续积累的「Wiki」。 整个系统分成三层： Raw 保存原始成功/失败轨迹； Wiki 把这些轨迹整理成失败模式、有效策略和历史经验； Skill 再把稳定下来的知识编译成 Agent 可以直接执行的流程。 每轮 Skill 更新都会经过验证。有效的留下，效果变差就回滚；但 Wiki 不会清空，所以失败的尝试也会成为下一轮进化的经验。 实验覆盖数学、搜索、Excel、长文档和具身任务等 5 个 benchmark、5 个模型。 结果是 Qwen-3.5-9B + WikiSkill 平均达到 47.4%，超过没有 Skill 的 Qwen-3.6-27B 的 39.4%。 而且 Skill 还能跨模型迁移。有些由其他模型进化出来的 Skill，甚至比模型自己的 Skill 效果更好。 这会让我比较关注 Wiki 这一层。 Agent 自进化如果只有「轨迹 → Skill」，很容易反复重新理解过去。中间多一层持续整理的知识库，才能让成功、失败和被拒绝的修改真正积累下来。 Skill 开始有点像独立于模型权重的知识资产：可以积累、验证、版本化，还能跨模型迁移。 📎 arxiv: https://t.co/ihDiNrRtTl

Claude Code v2.1.251 这次更新，在 Harness 层面又多了几个很关键的「观察点」。 最重要的是新增 PreModelSwitch 和 PostModelSwitch。 以后 Claude Code 切换模型时，外部 Hook 可以在切换前后介入，阻止、确认或者记录这次变化。 对多模型工作流来说，这个很实用。 以前你可以控制 Tool、Session、Subagent，现在连「什么时候换模型」这件事也开始进入可观测、可控制的生命周期。 另外 /cost 现在会直接显示当前 Session 的 Prompt Cache 命中率、miss、重新缓存了多少 Token，以及当前是 warm 还是 cold。 恢复旧 Session 时，Hook 甚至可以拿到它已经闲置了多久，以及预计重新建 Cache 的成本。 Remote Control 也补了一块：前台 subagent 在干什么、调用了什么工具、返回了什么结果，现在可以实时看到，不用再等任务跑完翻日志。 这几个更新放一起看，我觉得 Claude Code 的方向挺明显的。 它正在把 Agent 运行过程中原本藏在内部的状态，一点点开放给外面的 Harness。 模型切换、Cache、Subagent、成本，都开始可以被观察和调度。 另外这版还修了 symlink 路径穿越、plugin 路径越界等几个安全问题，建议直接更新。 https://t.co/E5rG4KI4bf

Some people worry that the rapid AI progress driving the "AI cybersecurity revolution" of 2026 could soon spill over into biology, potentially leading to extinction-level synthetic pandemics. While I would not panic, I would take the risk seriously. Biology is obviously not the same as cybersecurity -- cybersecurity is a fully verifiable domain, where you can synthetically train unbounded capabilities, and therefore where superhuman skill is straightforwardly achievable. Meanwhile biology is not a verifiable domain, so capability remains critically dependent on human-generated data. Plus, biology has critical non-digital bottlenecks, such as the requirement for physical wet-lab experimentation. However, it is plausible that synthetic pandemics were already feasible without AI, and that AI might lead to the proliferation of these capabilities. That is a real risk, and we are not prepared for it.

有些人担心，推动 2026 年“AI 网络安全革命”的 AI 快速进展，可能很快会外溢到生物学领域，潜在导致灭绝级的合成大流行病。 我不会恐慌，但我会认真对待这种风险。 生物学显然不同于网络安全。网络安全是一个完全可验证的领域，你可以用合成方式训练出无边界的能力，因此超人水平的技能相对容易实现。而生物学不是一个可验证领域，所以能力仍然严重依赖人类生成的数据。此外，生物学存在关键的非数字瓶颈，例如必须进行实体湿实验室实验。 不过，合成大流行病即使没有 AI 也可能已经可行，而 AI 可能导致这些能力扩散。这是真实风险，而我们对此并没有准备好。

It’s less about “code” vs anthropomorphism and more whether your choice of abstraction is smuggling in unsupported conclusions about the underlying mechanisms. The concerning thing here is that powerful optimization produced hacking, coordination, and circumvention of control! I don’t think we understand it better by reaching for the most anthropomorphic narrative.
