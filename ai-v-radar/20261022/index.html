P0AI 搜索 / 产品10-22 05:04 北京

Sharing new post-training research on self-distillation + RL (JOLT), done together with @NVIDIAAI. In self-distillation, the same model performs the role of both a teacher and a student. The teacher gets extra information that the student doesn't, and the student learns from feedback provided by the teacher. However, the teacher could still use shortcuts in ways the student has no way to follow. Our proposed approach, JOLT, trains the teacher as well, to learn from rewards on its own attempts, while penalizing any drift that's far off from what the student model would do. JOLT+ further supplements JOLT by providing the student model outcome-based rewards in addition to the teacher supervision signals. On the MATH benchmark, we found that JOLT matches GRPO with 6.5x fewer training tokens, while JOLT+ convincingly beats GRPO across math, coding, terminal tasks, and tool use benchmarks.

分享我们与 @NVIDIAAI 合作完成的后训练新研究：自蒸馏 + 强化学习（JOLT）。 在自蒸馏中，同一个模型同时扮演教师和学生。教师会获得学生没有的额外信息，学生则从教师提供的反馈中学习。但教师仍可能走一些学生无法效仿的捷径。 我们提出的 JOLT 也会训练教师，让它从自身尝试获得的奖励中学习，同时惩罚与学生模型行为偏离过大的情况。JOLT+ 在此基础上，除了教师监督信号，还为学生模型提供基于结果的奖励。 在 MATH 基准测试中，JOLT 仅用 GRPO 约 1/6.5 的训练 token 就达到了相当的表现；而 JOLT+ 在数学、编程、终端任务和工具使用基准测试中均显著优于 GRPO。

如果你经常用 Claude Code 或 Codex，看到「Always Allow」最好别太顺手点。 这篇论文研究了一个很值得关注的风险： Agent 可以借一次看起来合理的授权，拿到之后持续生效的更大权限。 攻击者只需要把恶意上下文藏进代码仓库，让 Agent 在正常任务里申请一个范围偏大的长期规则。 你一旦批准，后面的同类操作就可能不再弹窗。 作者在 Claude Code 和 Codex CLI 上测试，58% 的实验实例成功诱导出了目标权限规则；在用户已经批准这些规则的前提下，后续无额外提醒的攻击成功率达到 81%。 这里最值得注意的，其实不是某一次越权。 而是权限一旦被「记住」，Human-in-the-loop 可能只在第一次出现，后面的风险却会持续存在。 以后再点「Always Allow」，最好先想一下： 我批准的是这一次，还是顺手给未来几十次也开了门？ 📎 arxiv: https://t.co/gu2ouQNsz9
