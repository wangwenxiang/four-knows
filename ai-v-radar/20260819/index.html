We formalize multi-turn information seeking as a k-underspecified constraint satisfaction problem, where k is the minimum number of variables jointly required to determine the target. MT-INFOSEEK instantiates it in 5,251 problems and 9,006 tasks spanning mathematics, logic, gene regulation, clinical decision pathways, and 20 Questions. Key findings. 1. Models detect that information is missing, but not how much. Performance decreases as underspecification increases. In logical problems with k=2, models underestimate the amount of missing information about four times as often as they overestimate it. 2. Detecting missing information differs from identifying which information is needed. Models often fail to select a minimal sufficient set of variables, and providing the true k helps only modestly. Many interactions end before the collected information determines the target.

我们将多轮信息检索形式化为一个 k 欠指定约束满足问题，其中 k 是共同确定目标所需的最少变量数量。 MT-INFOSEEK 将其具体化为 5,251 个问题和 9,006 个任务，涵盖数学、逻辑、基因调控、临床决策路径和 20 Questions。 主要发现： 1. 模型能发现信息缺失，但不知道缺多少。随着欠指定程度增加，性能会下降。在 k=2 的逻辑问题中，模型低估缺失信息量的频率约为高估的 4 倍。 2. 发现信息缺失不同于识别需要哪些信息。模型经常无法选出最小充分变量集，即使提供真实的 k，帮助也有限。许多交互在收集到的信息足以确定目标之前就结束了。

Do LLMs know when they have enough information to answer, and what to ask a human when they don’t? @_yepeng We spend a lot of time developing agents that can answer the questions we ask them. But the reverse direction gets much less attention: when the prompt does not contain enough information, can a model recognize what is missing and ask for it? Paper: https://t.co/xlWmIwZ4Mt Project: https://t.co/tY06kTBsyp For agents that interact with humans, biological systems, or clinical workflows, we need to evaluate not only whether they can answer questions, but also whether they know what they need to know before answering. (1) Consider an agent evaluating a patient with pelvic pain. The duration of the pain determines which diagnostic pathway applies, so until the agent asks about it, no downstream symptom or test is clearly relevant. (2) Now consider an agent reasoning about a gene regulatory network, where the outcome depends on the unknown states of several genes. Acquiring one of them can leave several outcomes possible, so the agent must identify the full set that determines the outcome. Both cases raise the same three questions. Does the model recognize that information is missing? Does it identify which information it needs? Does it know when it has enough to answer?

LLM 知道自己何时已有足够信息可以回答，以及信息不足时该向人类询问什么吗？@_yepeng 我们花了大量时间开发能回答我们问题的智能体。但反向能力受到的关注少得多：当提示中信息不足时，模型能否识别缺少什么并主动询问？ 论文：https://t.co/xlWmIwZ4Mt 项目：https://t.co/tY06kTBsyp 对于与人类、生物系统或临床流程交互的智能体，我们不仅需要评估它们能否回答问题，还要评估它们是否知道在回答前需要了解什么。 (1) 设想一个智能体在评估一位盆腔疼痛患者。疼痛持续时间决定适用哪条诊断路径，因此在智能体询问这一点之前，后续任何症状或检查都还无法明确判断是否相关。 (2) 再设想一个智能体在推理基因调控网络，其结果取决于多个基因的未知状态。获取其中一个状态后，仍可能存在多种结果，因此智能体必须识别出决定结果的完整信息集合。 这两个案例都提出了同样三个问题：模型是否能意识到信息缺失？是否能识别自己需要哪些信息？是否知道何时已有足够信息可以回答？
