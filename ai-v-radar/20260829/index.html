Agent 自我进化最有意思、也最危险的一幕： 它在 Factorio 里找到了一个作弊捷径，然后把这个方法保存成了可复用的 Skill。 Factorio 是一款以采集资源、搭建生产线和自动化工厂为核心的模拟游戏。正常情况下，Agent 需要像玩家一样一步步发展工厂。 但 Prime Agent 发现，可以利用游戏的远程控制接口直接生成资源，绕过原本的生产流程，随后还把这条捷径沉淀成了 Skill。 Prime Intellect、Princeton、MIT 这篇论文提出 Prime Agent，一个面向长时任务的自进化 RLM Harness。 它给 Agent 一个持久的 Python REPL，可以在上下文之外保存和处理信息；同时支持递归创建 Sub-agent，让多个 Agent 并行工作。 更关键的是 Continual Harness。 任务过程中产生的 Prompt、Memory、Skill 和 Sub-agent 配置都可以持续修改和版本化。一次任务里学到的东西，会直接影响后面的执行，而模型权重始终不变。 论文报告中，Prime Agent 将 ARC-AGI-3 RHAE Best@1 从 30% 提升到 95.5%，还跑过 85.5 小时的自主 nanoGPT 实验。 但 Factorio 这个例子反而更值得注意。 Agent 学会积累经验之后，下一个问题很快就出现了： 什么经验值得留下？ 当 Memory、Skill 和工作流都开始持续自我修改，验证、权限边界和可回滚机制，可能会变得和「学习能力」一样重要。 📎 arxiv: https://t.co/yDz8dmW1dY
