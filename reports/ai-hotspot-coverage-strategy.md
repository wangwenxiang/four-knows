# 每日 AI 技术热点策略

## 结论

目标不是收集“所有与 AI 有关的信息”，而是找到最近 23 小时已经表现出实际能力、产品影响或工程价值的技术变化。

## 保留的信号

1. 固定 54 个 X 账号最近 23 小时的一手内容。
2. 人工筛选、禁止自动扩张的 7 人扩展名单。
3. 上述人物引用或转发的原始技术内容；同一事件只保留一次。
4. 多个独立高信号人物在短时间内同时讨论的事件。
5. 五个重点方向中的权威人物、核心研究者，以及重要项目或核心团队的官方 X 账号。

## X 信号如何使用

X 是实时发现入口，不是单独的事实证明。以下账号可以作为候选事件的首发来源：

- 突破的直接负责人、论文或技术报告作者、项目技术负责人；
- 模型、Agent、机器人、生命科学或意识研究项目的官方账号；
- 对实验、评测或真实部署负直接责任的核心团队成员。

满足以下任一条件，X 帖子可以进入候选池：附有原始技术报告或实验链接；包含可核对的指标、演示或部署结果；由直接负责人发布并明确说明已经发生的技术变化。只有观点、转述、预测、营销文案或“听说”不能成为突破。

权威人物和项目账号按五个方向分别维护，新增必须人工确认；不会因为一次热门转发自动加入长期名单。

## 明确移除的信号

- arXiv 最新论文：离实际应用通常过远。
- OpenAI 等实验室新闻 RSS：与名单中的核心人物高度重复。
- Nature 等出版物来源：与日常 AI 产品和工程应用关联太弱。
- 普通 GitHub release：版本更新多、热点信号弱。

## 什么才算热点

至少满足一项：新模型或新能力已经可用；AI 产品出现明显的新交互或工作流；Agent、AI Coding、机器人等出现可验证演示；推理成本、速度或效果有明确数字变化；真实团队披露了生产部署效果。只有观点、预告、营销措辞、论文摘要或普通版本号变化的不算。

不能保证发现全球全部热点，但可以保证名单抓取失败时明确报错，且不会用弱内容补足日报数量。
